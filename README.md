# Garage19 — интернет-магазин багажных систем и фаркопов

Интернет-магазин багажников на крышу, автобоксов, велокреплений, лыжных креплений и фаркопов (ТСУ)
с подбором товаров по **марке → модели → поколению → модификации** автомобиля и полноценной админкой.

Стек: **Next.js 15** (App Router, Server Components, Server Actions) · **TypeScript** · **Tailwind CSS v4** ·
**PostgreSQL + Prisma 6** · Node.js 20+.

---

## Возможности

### Витрина

- **Главная страница**: слайдер с автопрокруткой, конфигуратор подбора автомобиля, категории, хиты, новинки,
  промо-блоки, блок «Гараж», SEO-текст.
- **Конфигуратор**: марка → модель → поколение → модификация. Явное поле «поколение» есть только у одного
  из конкурентов, поэтому справочник ведётся вручную — с реальными годами выпуска.
- **Каталог**: дерево категорий, фасетные фильтры (производитель, цена, наличие, место установки, материал,
  грузоподъёмность, объём, замок, электрика, вырез бампера), сортировки, пагинация, вид «плитка/список»,
  подбор по авто внутри категории, чипсы активных фильтров.
- **Карточка товара**: галерея, цена со скидкой, наличие, характеристики, совместимость с автомобилями,
  PDF-документы (инструкция, **паспорт и сертификат для фаркопов**), аксессуары, **аналоги**,
  отзывы с модерацией, **вопросы и ответы**, доставка и оплата.
- **Корзина и оформление**: гостевая корзина (cookie) и корзина пользователя (БД), промокоды,
  выбор города и способа доставки (самовывоз, СДЭК ПВЗ/курьер, Boxberry, Почта России, курьер по городу),
  расчёт стоимости доставки, оплата онлайн/при получении/по счёту, запись на установку.
- **Личный кабинет**: заказы и повтор заказа, профиль и адреса, отзывы, **«Гараж» — сохранённые автомобили**.
- **Страницы**: доставка, оплата, гарантия, возврат, установка, оферта, о компании, контакты, подбор по VIN.
- **SEO**: ЧПУ, метаданные и Open Graph, микроразметка Schema.org (Product, BreadcrumbList, ItemList,
  AutoPartsStore), sitemap.xml, robots.txt, SEO-посадочные `/podbor/{марка}/{модель}/{поколение}`.

### Админка (`/admin`)

- Дашборд со сводкой по заказам, выручке, товарам без наличия и без совместимости.
- Каталог: товары (все поля модели, изображения, документы, характеристики, совместимость, связи),
  категории, характеристики, производители.
- Справочник автомобилей: марки, модели, поколения, модификации; массовая привязка совместимости.
- Импорт прайсов поставщиков **XML / YML / CSV** с наценкой, режимами (обновление/только новые/проверка)
  и журналом задач.
- Заказы с историей статусов, заявки (обратный звонок, вопрос, VIN, установка, опт), отзывы с ответами.
- Баннеры, страницы, города и тарифы доставки, пункты выдачи, поставщики, пользователи и роли, настройки.
- Аудит действий, роли `admin` / `manager` / `customer`.

## Быстрый старт

```bash
# 1. Зависимости
npm install

# 2. Переменные окружения
copy .env.example .env      # Windows
cp .env.example .env        # Linux/macOS

# 3. База данных (PostgreSQL 16)
npm run db:push             # применить схему
npm run db:seed             # залить демо-каталог, авто, баннеры, страницы

# 4. Запуск
npm run dev                 # http://localhost:3000
```

Админка: `http://localhost:3000/admin` — логин `admin@garage19.ru`, пароль `Garage19!Admin`
(значения из `ADMIN_EMAIL` / `ADMIN_PASSWORD` в `.env`, создаются сидером).

Подробности по локальной БД — [docs/DATABASE.md](docs/DATABASE.md).

## Скрипты

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Дев-сервер на `http://localhost:3000` |
| `npm run build` | `prisma generate` + production-сборка |
| `npm run start` | Запуск собранного приложения |
| `npm run typecheck` | Проверка типов (`tsc --noEmit`) |
| `npm run db:push` | Синхронизировать схему со БД |
| `npm run db:seed` | Демо-данные |
| `npm run db:studio` | Prisma Studio |
| `npm run db:reset` | Пересоздать схему и залить демо-данные |

## Что отличает проект от конкурентов

По результатам анализа 14 сайтов нишевые конкуренты не реализуют:

1. «Гараж» сохранённых автомобилей в личном кабинете.
2. Подбор по VIN хотя бы в виде заявки менеджеру.
3. Блок «Аналоги/замены» в карточке товара.
4. Проработанный сценарий «нет моей модификации» в конфигураторе.
5. Фасеты «замок», «материал», «количество дверей».
6. Доставку Почтой России и Boxberry.

Всё это в проекте реализовано.
