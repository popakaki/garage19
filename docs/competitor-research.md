# Конкурентный анализ: e-commerce в нише автомобильных багажных систем (РФ/СНГ)

**Дата исследования:** текущая сессия. **Метод:** прямые `web_fetch` реальных страниц (главная, подборщик, каталог, карточка, корзина, доставка/оплата, сервис) + `web_search` для поиска лидов.

**Легенда достоверности:**
- ✅ **Подтверждено** — прочитано на реальной странице, ниже есть ссылка.
- ⚠️ **Предположение** — вывод по косвенным признакам, требует проверки.
- ❌ **Не подтверждено** — сайт недоступен из окружения анализа.

1. **Поколение почти всегда скрыто.** Единственный сайт, где «Поколение» — явное отдельное поле, — [farkop.ru](https://farkop.ru/catalog/farkopy/). У остальных оно «вшито» в модификацию.
2. **Год vs поколение.** [es-farkop.ru](https://es-farkop.ru/) ставит на второе место **Год**, а не модель — это работает для фаркопов, но для багажников неудобно (нужен тип крыши, а не год).
3. **Госномер-подбор в РФ-нише не найден ни у одного магазина.** ✅ Только у западного [brink.eu](https://brink.eu/en-gb/how-does-it-work). ⚠️ Для РФ это требует интеграции с API ГИБДД/РСА и юридически чувствительно.
4. **VIN-подбор в РФ-нише тоже не найден как поле ввода.** ✅ Подтверждено только как тема экспертной статьи: [«Подбор фаркопа по VIN: когда он нужен и как это работает»](https://pricep-vlg.ru/145207-2/) — там VIN передаётся **менеджеру вручную**. Это **чистая незанятая ниша**.
5. **Сохранение авто между сессиями** — визуально не подтверждено ни на одном сайте. ⚠️ [es-farkop.ru](https://es-farkop.ru/) имеет ЛК, «Мои заказы» и запоминание города — вероятно, гараж авто там возможен, но подтвердить без авторизации нельзя.
6. **Что делать при отсутствии точного совпадения** — ни на одном сайте нет явного сценария «нет вашей модификации». Все показывают либо результаты, либо пустоту. ⚠️ Это незакрытая дыра в UX у всех конкурентов.

### 8.2 Что нужно построить (вывод из продуктовой логики, ⚠️ предположение)

**Минимально необходимый бэк-офис для такой ниши:**

1. **Двухуровневая модель данных каталога:**
   - *Товар* (SKU, бренд, цена, наличие, габариты, вес, грузоподъёмность, объём, профиль, материал, замок, гарантия, фото, PDF-инструкция, PDF-сертификат).
   - *Применимость (fitment)* — отдельная таблица связи `make → model → generation → modification (кузов/год/двигатель/тип крыши)` ↔ SKU. Это ядро системы; у всех конкурентов она есть, и именно её качество определяет конверсию конфигуратора.
2. **Импорт прайсов поставщиков XML/CSV/XLS** — критично, т.к. ассортимент приходит от TowRus, Baltex, Oris, Auto-Hak, Galia, Turtle, Lux, Atlant, Piligrim/ED, Menebo, Thule и др. Требуется маппинг колонок + нормализация названий авто к внутреннему справочнику (иначе fitment не соберётся автоматически).
3. **Склад/наличие** с разделением «свой склад / склад поставщика / под заказ» — конкуренты показывают точное количество («В наличии: 45 шт») ✅.
4. **Цены и наценки** — правила наценки по бренду/категории, RRP поставщика, скидки, промо-акции (подтверждённые форматы: «Скидка до 25% на установку», «Купон на скидку», «Аренда кемпера в подарок»).
5. **Характеристики** — наследуемые от категории свойства (у Битрикса — свойства инфоблока) для фасетного фильтра.
6. **Управление совместимостью** — массовая привязка SKU к диапазонам авто, загрузка справочника make/model/generation/modification, ручные исключения.
7. **Контент-менеджмент** — статьи, обзоры товаров, портфолио работ, FAQ, видео-отзывы (всё это реально ведётся у farkop.ru).
8. **Промо** — акции с посадочными страницами (`/akczii/{slug}/`), баннеры, бейджи `new`/`best` (es-auto.ru).
9. **Заказы** — корзина, 1-click, статусы, уведомления, интеграция с CRM.
10. **Экспорт заявок в 1С** — ⚠️ прямых доказательств обмена с 1С нет; подтверждён только Битрикс и Битрикс24 (CRM). Стандартный для Битрикс модуль обмена с 1С — вероятен, но не доказан.
11. **Роли/права** — контент-менеджер / менеджер заказов / оператор установки / администратор. Без публичных подтверждений.
12. **SEO-поля** — title/description/H1/canonical/alt для товаров, категорий, **и для страниц совместимости** (это ключевой SEO-актив). Подтверждено, что конкуренты это эксплуатируют: [bgznk.ru/catalog/bagazhnik-na-kryshu/toyota/camry](https://www.bgznk.ru/catalog/bagazhnik-na-kryshu/toyota/camry/) с осмысленным title.

## Приложение: сводка незанятых возможностей (рыночные «дыры»)

Все пункты ниже — **подтверждённое отсутствие у 8+ проверенных конкурентов**:

1. 🕳️ **Гараж сохранённых автомобилей** — не делает никто.
2. 🕳️ **VIN-подбор** — не делает никто (только описано как боль в контенте конкурента).
3. 🕳️ **Госномер-подбор** — только западный brink.eu.
4. 🕳️ **Сценарий «нет моей модификации»** — не проработан нигде.
5. 🕳️ **Какого-либо блока «Аналоги»** в карточке — нет ни у кого.
6. 🕳️ **Фасеты «замок», «материал», «кол-во дверей», «водосточные желоба»** — не реализованы; замок встречается только в названии товара.
7. 🕳️ **Рассрочка/BNPL** — не предлагает никто.
8. 🕳️ **Почта России / Boxberry** — не подключены нигде.
9. 🕳️ **Видео-обзор в карточке товара** — нет ни у кого.
10. 🕳️ **Онлайн-эквайринг** — отсутствует у [vse-bagazhniki.ru](https://vse-bagazhniki.ru/oplata) (заказ письмом + счёт), т.е. даже базовая гигиена закрыта не всеми.
